# Compás

Метроном фламенко для компьютера и iPhone. HTML, CSS и JavaScript без сборки и внешних библиотек. Звуки встроены в приложение; после загрузки страницы для воспроизведения интернет не нужен.

## Запуск

Откройте `index.html` в браузере и нажмите «Начать». Для проверки с iPhone можно раздать папку приложения HTTP-сервером в одной сети Wi-Fi. Публикуйте только файлы приложения, без локального архива IPA.

## Возможности

- 30 рисунков в 13 разделах: Bulerías, Soleá, Soleá por bulerías, Alegrías, Tangos, Tanguillos, Tientos, Rumbas, Fandangos, Jaleos, Seguiriyas, Sevillanas и Palmas.
- Все 27 конфигураций из Metronomo и три дополнительных учебных рисунка. Sevillanas сохраняет полные последовательности со вступлением и паузами.
- Темп 40–300 BPM: ввод числом, ползунок и кнопка «Тап». На компьютере также доступны «+» и «−».
- Отдельная кнопка «Начать с 9» в рисунках с девятым счётом. Звук и визуальный счёт начинаются с 9; далее повторяется полный цикл. При игре кнопка перезапускает рисунок с 9.
- Тангос на четыре счёта 1–2–3–4; исходная фраза занимает два круга.
- Наборы звуков Metronomo и «Студийный», отдельные громкости и отключение пальмас, кахона и пандереты.
- Компактная мобильная страница с крупным циферблатом и закреплёнными кнопками старта.
- Настройки сохраняются в браузере. Пробел запускает и останавливает воспроизведение на компьютере.

## Устройство проекта

- `index.html`, `style.css`, `app.js` — интерфейс и движок Web Audio.
- `sample-data.js`, `iphone-samples.js` — встроенные звуковые банки.
- `iphone-patterns.js` — каталог и сетки ритмов.
- `assets/` — исходные звуковые файлы, конфигурации, сведения о происхождении и лицензиях.
- `import-iphone.py` — извлечение всех 27 рисунков и звуков из локального пользовательского архива, без запуска приложения. Архив в репозиторий не включён.
- `download-samples.py` — подготовка студийного банка; для пересборки нужны Python 3 и FFmpeg.
- `docs/development-notes.md` — записи об анализе и развитии приложения; некоторые разделы описывают предыдущие версии.

Движок планирует события на 150 мс вперёд, используя сетку в одну восьмую исходной единицы BPM. Темп меняет интервалы между ударами, а не скорость самих записей. В конфигурациях с `tempoFraction` визуальный счёт может включать несколько позиций на один пульс BPM.

## Звук и происхождение

Студийные записи происходят из Freesound, FreePats и Karoryfer; сведения об источниках и лицензиях находятся в `assets/`. Банк Metronomo извлечён из предоставленного пользователем архива: лицензии CC0 студийных записей к нему не относятся. Общая лицензия на сторонние записи не назначается.

Позиции событий и полные последовательности перенесены из исходных конфигураций. Формула интенсивности и соответствие дополнительных типов хлопков исходным индексам восстановлены приближённо. Исходные WAV сохраняют уровни и атаки; перед суммированием некоторым рисункам задан общий запас по громкости.

Для практики держите страницу открытой: после блокировки экрана, сна устройства или прерывания аудио браузером может понадобиться повторный запуск.
